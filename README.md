# JWo1F/homebrew-tap

Homebrew formulae for [icofon](https://github.com/JWo1F/icofon).

```bash
brew tap jwo1f/tap
brew install icofon
```

Or in one line, without tapping first:

```bash
brew install jwo1f/tap/icofon
```

## Formulae

| Formula | What it is |
| --- | --- |
| `icofon` | Build an icon font (TTF + CSS) from a folder of SVG files |
